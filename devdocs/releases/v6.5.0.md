# DTFlow 6.5.0

Prepared 2026-11-23. Changes since [6.4.1](v6.4.1.md).

## Highlights

- **Create and browse videos.** Generate supported DT+ videos, optionally from a start image, queue several clips and play saved videos directly in Images.
- **Guide images with poses.** Use a photograph or prepared body map in Controlnet, then reuse the pose in queues and local templates.
- **Keep track of every run.** Generate shares queue history and scheduling, multi-result runs have a result grid, and one activity bar summarizes ongoing work.

## Added

- Video playback in Images Detail with seeking, mute, restart, optional Autoplay and keyboard shortcuts. Video durations appear in Grid, List and the filmstrip.
- Video queues with optional retained start images and per-clip progress. Connection controls provider concurrency, simultaneous local encoders and encoder threads.
- Export saved MP4s without re-encoding, or Trash/Delete clips together with their posters. History and metadata remain retained.
- Controlnet pose guidance on DT+ Cloud, with person selection for photographs and editable control strength and range. Queue drafts support pose editing and explicit body-map replacement; pose templates retain their own map.
- A tiled result grid for Generate batches, with visible-image previews, saved video posters and click-through to the exact result in Images.

## Changed

- Single Generate requests now appear in Queues and take the next available generation slot ahead of unsent batch work. Stop targets the displayed request; Retry creates another attempt for that item.
- Queues, Scripts and Workflows share provider slots. Images release their slot after sampling rather than waiting for download and saving; videos release it after receiving.
- The bottom activity bar summarizes active queues with coloured segments and a named Stop target. Queue controls remain on the Queues page; the old header progress ring is removed.
- Video frames are received to disk before local encoding, with a visible wait when all encoders are busy. Local frame conversion uses an optimized decoder by default; performance varies with hardware and workload.
- Windows builds include the video tools they need. Windows source installs use the same pinned tools rather than whichever FFmpeg happens to be on PATH; see [Windows builds](../guides/building.md).
- Generate remembers its mode, while startup always opens Connection. Samplers are sorted alphabetically, and the queue composer separates fixed LoRAs from weight variations.

## Fixed

- Addressed the Images freeze after repeated video starts, reused the video player between clips and reduced unnecessary loading during rapid navigation.
- Kept video information and slideshow controls visible during playback, and gave autoplaying slideshow clips time to start before advancing.
- Reduced repeated LoRA-table rebuilding and column sizing, and moved catalogue preparation off the UI thread while preserving selection.
- Deferred remembered Controlnet and Inpaint source preparation until the corresponding editor is opened.
- Preserved exact pose settings and maps through queue creation, Retry, Relaunch, Edit as new and template reuse; refreshed the current pose when creating a new queue plan.
- Corrected video disk reservations and resource waiting, second-pass progress, queue handoffs, notice dismissal and stale fixed-LoRA bindings in reconstructed drafts.
- Removed the internal Fake provider from desktop choices; it remains available for development and CLI use.

## Upgrade and compatibility

- Close DTFlow and back up its complete state directory and original outputs before upgrading. Execution-state schema remains **9** and the LoRA registry remains **6**. Keep a pre-upgrade backup if you may downgrade; older versions cannot use every new record type.
- Pose-template libraries remain schema **1**; pose recipes use version **2**. Older applications refuse libraries containing these recipes. Reinstall the pose detector once from the Pose guidance card to use YOLO26n-pose.
- Verified pose guidance is limited to FLUX.1 Dev q5p with Union Pro 1.0 q5p at strength 0.7; other checkpoint combinations are not verified.
- Video generation requires a supported DT+ model and consumes credits. Video retries are manual, retained queue start images are not automatically cleaned, and video templates or Script/Workflow video steps are not included.
- The minimum window width is now 1000 px. Existing saved state and uncertain work are not automatically replayed.

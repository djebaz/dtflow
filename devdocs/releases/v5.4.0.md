# DTFlow 5.4.0

Release preparation: 2026-10-26. Source changes are merged; final release checks and exact Windows executable acceptance remain separate from publication.

## Highlights

- Independent thumbnail zoom for Images Grid, List and Detail filmstrip views.
- Prompt variation tags and a prompt/LoRA hover overlay in Images Detail.
- Ctrl+Enter submission from prompt editors and plain mouse-wheel zoom in Generate and Inpaint previews.

## Added

- Hovering the Images Detail info button shows the full positive prompt and recorded LoRAs. The image path remains in Additional details rather than a routine image tooltip; image problems still have tooltips.
- Resolved prompt variations carry recorded text spans for tag presentation in queue and image views. Prompt evidence is retained with the existing request/queue records.
- Ctrl+Enter, including keypad Enter, activates the prompt editor's own enabled action: Generate/Edit image, or the queue composer's Start now/Add to queue action. It never selects Save paused, repeats submissions through key auto-repeat, or bypasses pending inline consent.

## Changed

- Grid, List and Detail each remember their own 25–250% thumbnail zoom. Switching views restores that view's value; Detail's full-image zoom remains independent.
- Generate and Inpaint previews accept the plain mouse wheel for zoom. Preview controls and Images Detail presentation were refined.
- Interface wording is simpler and more consistent across connection, generation and queue controls.

## Fixed

- Slow Windows fixture runs have longer bounded waits for gallery presentation and queue concurrency checks. These are test timing changes, not a claimed runtime speedup.

## Upgrade and compatibility

- Close other instances and back up the full durable state directory and original outputs before upgrading. Do not run concurrent Windows/WSL SQLite writers or replay uncertain attempts.
- Viewer preferences now store `thumbnail_scale_percents` for the three views. A valid legacy shared `thumbnail_scale_percent`, or older pixel density, seeds the three values. Older versions do not understand per-view zoom; keep a backup before downgrading.
- The execution database remains schema 4; the queue-template library remains version 1. This release does not change credential selection, provider compatibility or dispatch consent.

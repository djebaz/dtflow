# DTFlow 5.5.6 release preparation

Date: 2026-11-07. Owner-selected version: 5.5.6 (5.5.3 to 5.5.5 were never released). Build path: **Build Windows EXE and draft release** (`build-and-release.yml`).

## Scope and baseline

- Baseline: merged main `95a2c096d327a6cf7c990f3a917de55da648e915`. Published predecessor: [5.5.2](https://github.com/djebaz/dtflow/releases/tag/v5.5.2).
- Open PRs #253 and #254 are not merged and not part of this release.
- Only DTFlow's own version changes in `pyproject.toml` and `uv.lock` (lock revision unchanged). [Versioned notes](../releases/v5.5.6.md) consolidate the post-5.5.2 changes.

## Validation

- Owner instruction: no local tests; GitHub CI is the test evidence. Local checks: `uv lock --check`, Ruff lint/format. Exact-head CI results are recorded on the release PR.
- No model download, training, inference, upload or provider call is part of preparation.

## Delivery gates

1. Release PR with passing CI on its final head; squash merge.
2. Push annotated `v5.5.6` on the merged commit, dispatch `build-and-release.yml` from main with `release_tag=v5.5.6` (after checking no run is already active for that tag).
3. Verify draft asset identity, checksum and manifest; owner smoke-tests the exact executable.
4. Publish the existing draft only after owner acceptance and approval.

A tag, successful build or draft is not a shipped release.

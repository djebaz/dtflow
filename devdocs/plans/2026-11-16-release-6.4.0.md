# DTFlow 6.4.0 release preparation

Prepared 2026-11-16 from merged main `d14c0ece` (PR #480), after published `v6.3.0`. Release PR: [#481](https://github.com/djebaz/dtflow/pull/481). Public notes: [6.4.0](../releases/v6.4.0.md).

## Release path and gates

- No GitHub Actions dispatches: owner reports credits exhausted; automatic CI/Preview triggers are already commented out.
- Release preparation changes version metadata and documentation only. Preserve all merged behavior and locked dependency versions.
- Owner builds locally from the exact approved squash-merged release commit, using the canonical builder and locked quantization group with temporary PyInstaller 6.22.3. No agent build is requested.
- Verify the EXE's clean bundled commit/version, SHA256, size and generated manifest. Owner accepts that exact executable before tagging/publication; a failed gate means no release. The local-build path tags only after acceptance.
- Do not repeat credit-consuming provider work or infer broad model/GPU equivalence from selected source smoke.

# DTFlow design system (Claude Design export)

Web reference for the Qt app's design language: tokens, components, foundation
cards and UI kits. It is a prototype and review aid, not runtime code. The Qt
app still reads `src/dtflow/resources/styles/tokens.json` and `dtflow_dark.qss`.

- `tokens/colors.css` mirrors every `color.*` entry in `tokens.json`. Colors
  under "Component-local tones" come from one-off QSS rules and are not global
  tokens (see `DESIGN.md`).
- `assets/icons/*.svg` are copies of `src/dtflow/resources/images/gallery/`.
- `_ds_bundle.js`, `_ds_manifest.json` and `_adherence.oxlintrc.json` are
  generated by Claude Design; do not edit them by hand.
- Fonts: Noto Sans / Noto Sans Mono stand in for Segoe UI / Consolas.

When `tokens.json` changes, update `tokens/colors.css` and the `DESIGN.md`
snapshot in the same PR.
